### 🏦 Credit Risk MLOps — End-to-End Pipeline on AWS
Full-lifecycle MLOps system for credit default risk scoring: Glue ETL → SageMaker Pipelines (training, governance, Model Registry) → **dual deployment** (native SageMaker Endpoint + FastAPI/Docker/ECS Fargate/API Gateway) → A/B tested (10/10 prediction match) → drift monitoring (validated against real simulated drift, z-score 6.67) → automated retraining via Lambda + EventBridge. Entire infrastructure defined as code with Terraform; CI/CD with GitHub Actions.
